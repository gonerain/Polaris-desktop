# 日程：轻量操作，可靠落盘

## 取舍与参考

- [Things](https://culturedcode.com/things/features/)：借鉴日常任务入口简洁、跨日期 Upcoming 与即时搜索的分工，不照搬其视觉资产。
- [Todoist Upcoming](https://www.todoist.com/help/articles/plan-your-week-with-the-upcoming-view-OKOg1mR8)：借鉴按日期管理与便捷改期；本版以明确的日期输入和“移到今天”实现，不宣称支持自然语言或拖拽。
- 保留现有 2×1 日程全部常用功能；完整态不是使用功能的强制中转站。
- 紧凑视图不增加搜索、筛选工具条；完整态提供“日历 / 待办”两个明确入口。
- 使用现有 Theme、低对比悬停、轻量分隔、统一按钮与短动效，不依赖 GPU 阴影或模糊。

## 操作

- 紧凑态：前后一天、回到今天、月历、快速添加、编辑时间和标题、完成任务、子任务。
- 时间点选弹层：小时/分钟支持点击、拖动及真实鼠标滚轮；触控板/高分辨率滚轮累计小幅增量，两列独立并支持循环。有“全天”“现在”；确定才修改，点外部或 Esc 取消。不要求手填格式。弹层复用当前窗口的 Overlay，避免创建透明原生窗口时的闪烁；大小限制在展开窗口内。
- 点背景提交已有行内编辑、收起添加条和子任务；点输入框、按钮、子任务区域不误收起。未提交的添加/子任务草稿在本次视图内保留，再打开可继续。
- 正常保存完全静默，没有常驻成功提示或为此占用的底栏；只有删除撤销、恢复通知或实际错误才显示反馈。
- `Ctrl+N` 打开添加条，`Ctrl+T` 今天，`Alt+←/→` 前后一天。
- `↗` 打开总览。日历视图并排显示月历和当日日程；小宽度上下排列。
- 待办视图聚合所有日期，默认隐藏已完成任务；搜索匹配任务名、子任务名、日期，可选“含已完成”。按日期、全天优先及时间排序。
- 待办条目上方可编辑 `YYYY-MM-DD` 日期；非法日期拒绝并标红。逾期任务可一键移至今天。逾期在本版指**今天以前**的未完成任务，不指今天早些时候的定时任务。
- 删除主任务后底部提供单步撤销，恢复其日期、ID、子任务及完成状态。仅保留本次运行的最近一次主任务删除；子任务删除不支持撤销。
- 完整态下 Esc 先关闭添加条，再返回画布，不与两个视图的快捷键争抢。
- 托盘提供打开日程、数据文件夹、退出，以及系统原生提醒通道。托盘不可用时仍保留桌宠右键退出。

## 存储和恢复

Windows 正常启动使用 `QStandardPaths.AppLocalDataLocation`，应用/组织名均为 Polaris，通常是 `%LOCALAPPDATA%\Polaris\Polaris`。

- `tasks.json`：版本化 UTF-8 JSON，包含日期、稳定任务 ID、标题、时间、完成状态与一级子任务。
- 每次有效修改同步写入；`QSaveFile` 原子替换，不先截断已有文件。失败时保留内存修改，并在组件底部明确显示错误与重试入口，不显示“已保存”。正常退出会再次尝试保存；仍失败则必须明确选择“仍然退出”，不静默丢弃。
- `tasks.json.bak`：上一次完整有效快照。备份也使用原子替换；备份写失败时不继续覆盖主文件。首次写入没有历史备份。
- 主文件缺失/损坏时尝试加载有效备份。损坏原件另存为 `tasks.corrupt-时间戳.json`，界面提示恢复情况。**备份只保留上一版本，不等于完整历史，也不能保证包含最后一次修改。**
- 主文件和备份都无法读取、或遇到不支持的数据版本时，停止自动写入，显示错误，避免用空列表覆盖原件。修复文件后需重启；“重试保存”只用于可恢复的磁盘写入错误，不解除数据保护。
- 运行中检测到主文件格式损坏，同样停止覆盖。
- `app.lock` 使用 `QLockFile` 防止正常版本重复运行及并发写入。锁冲突时弹出 Windows 提示，不再创建另一条鱼。旧的、未实现锁的可执行文件不受此机制控制，应退出后再使用新版。
- 托盘菜单可打开数据文件夹。手动备份可以复制 JSON；手动恢复应先退出应用、保存当前文件副本，再替换 `tasks.json`。
- 数据未加密，不包含账号或云同步；不要把本地文件放进仓库。

午夜后每 30 秒更新“今天”；若正在看昨天（原来的今天），自动跟随到新的一天；浏览其他日期时不打断。导航不会重复写入未修改的日程。

`create_engine()` 默认不接入真实存储，测试不会接触个人数据；正常 `main()` 显式指定用户数据路径。存储测试全部使用临时目录，并覆盖写失败、损坏恢复、禁止覆盖、子任务修改、ID 恢复和跨天刷新。

## 已知边界

- 提醒仍按运行期提前十分钟规则；托盘原生通知受系统勿扰、系统权限和托盘可用性影响。不是系统级闹钟，不保证关闭程序后的提醒，未实现到点补报或跨重启去重。
- 暂无重复日程、云同步、拖拽改期、自动备份历史或导入向导。
- 未提交的“添加任务”草稿不是任务，不自动落盘；已有任务的行内编辑在 Enter、失焦、缩回或正常退出时提交。
- 窗口位置、大小和界面筛选未持久化。
- 已复现并修复悬停移入/移出的闪暗：Qt 的 `transparent` 是透明黑，直接与浅色做 `ColorAnimation` 会经过明显偏暗的中间帧。动画背景统一使用保留白色 RGB 的零透明度 `Theme.clearSurface`；按钮、输入框、日期格、任务卡均覆盖进入、退出与快速反向切换的逐帧回归测试。正常启动保持 Qt 默认渲染后端，不再用强制软件渲染掩盖颜色问题；时间弹层仍复用主窗口表面。
- 离屏软件渲染测试验证布局、事件、动画中间帧和几何，不替代真实 Windows 悬停、多显示器动画及系统通知的人工验收。
