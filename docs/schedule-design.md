# 日程：轻量操作，可靠落盘

## 取舍与参考

- 主要参考 [Super Productivity 官方手册](https://super-productivity.com/guides/the-super-productivity-handbook/)、[First Steps](https://github.com/super-productivity/super-productivity/blob/master/docs/wiki/1.01-First-Steps.md) 与[官方界面](https://super-productivity.com/press-kit/)：任务为中心，今天是主动承诺的清单，详情按需展开，规划与执行分开。
- 借鉴其工作流和信息层级，不复用品牌图片、不移植 Web 架构。Polaris 的“收集箱”按未安排日期定义，“任务库”聚合全部未完成任务，与 Super Productivity 按项目归属定义的 Inbox 并非同一数据模型。不为照搬产品而引入项目、同步或虚假的工时统计。
- 保留现有 2×1 日程全部常用功能；完整态不是使用功能的强制中转站。
- 紧凑面板每次展开默认回到“我的一天”，已完成任务按需展开。完整态为任务工作台，侧栏区分我的一天、收集箱、任务库、待重新安排、周计划、月计划和已完成；窄窗口缩为可滚动导航条。日历和详情按需展开，不常驻占位。
- 使用现有 Theme 的冷灰底、白色任务卡、紫蓝选中态和暖色过期提示，统一按钮与短动效；低频删除、子任务添加在悬停或编辑时出现，不依赖 GPU 阴影或模糊。

## 操作

- 紧凑态：今天待办、前后一天、回到今天、按需月历、快速添加、编辑时间和标题、完成任务、子任务。过期待办显示轻量提示，可直接全部移到今天。
- 时间点选弹层：小时/分钟支持点击、拖动及真实鼠标滚轮；触控板/高分辨率滚轮累计小幅增量，两列独立并支持循环。有“全天”“现在”；确定才修改，点外部或 Esc 取消。不要求手填格式。弹层复用当前窗口的 Overlay，避免创建透明原生窗口时的闪烁；大小限制在展开窗口内。
- 焦点只遵循一个规则：点当前输入框内保留焦点，点框外取消焦点。点击另一个输入框时，由 Qt 正常聚焦新框；不单独实现“转移焦点”逻辑。`polaris/input_focus.py` 在窗口接收点击前统一处理，不再递归判断输入边界。
- 点背景还会收起添加条和子任务；点按钮或编辑区域内部不误收起整块区域，但不再因此保留旧输入焦点。点击桌面/其他应用会清除持有的文本焦点，再激活窗口时不自动恢复放弃的输入。未提交的添加/子任务草稿在本次视图内保留，再打开可继续。只读时间触发器不显示文本编辑边框。
- 正常保存完全静默，没有常驻成功提示或为此占用的底栏；只有删除撤销、恢复通知或实际错误才显示反馈。
- `Ctrl+N` 打开添加条，`Ctrl+T` 今天，`Alt+←/→` 前后一天。
- `↗` 打开完整态，默认“我的一天”，不加载日历。今天只显示日期为今天的未完成事项，不把过期任务自动混进来；旧安排只显示整理提示，单独查看或主动加入今天。完成进度只使用真实任务数量。
- 工作台使用紧凑任务行：勾选直接完成，点击行才打开任务详情，详情内编辑标题、时间和子任务。宽窗口放右侧，窄窗口放下方；同一任务的内容刷新不清除子任务草稿，主动切换另一任务时清空未提交的子任务输入，避免串到另一任务。
- 收集箱先记事、不要求日期，不计入今天和逾期，不发送提醒；可直接加入今天或点选日期。紧凑添加条可切换“当天 / 收集箱”，底部提供收集箱入口。任务库和收集箱里的全局添加默认“随手记下”，不会悄悄安排到今天。
- 今天任务左侧的三点手柄可拖动排序，靠近列表边缘自动滚动；Esc 或拖出列表取消。顺序持久化，不再被修改时间自动打乱；周/月计划仍按时间展示。星标可以设置重点，建议每天选择 1–3 项，但不硬性限制数量，也不强行改变手排顺序。
- “下一步与笔记”只在任务详情里出现，空笔记默认折叠；支持多行纯文本，失焦、切换任务或正常退出时保存到正确的任务，不把旧内容写入新选择的任务。
- “整理今天”展示完成情况和未完成任务；逐项选择保留今天、安排明天或放回收集箱，也可批量选择。默认全部保留，取消不做修改，确认后一次保存；完成记录仍留在原日期，不自动顺延或删除。整理以打开时的日期为准，跨午夜也不误处理新一天。
- 全局搜索会进入任务库，匹配所有未完成任务、子任务、笔记和日期，不受今天的范围限制。已完成记录独立查看。
- 周日程按周一至周日分栏，显示时间和任务，可直接勾选完成；月日程显示任务摘要与溢出数量，只保留该月需要的周数。支持前后周/月导航、回到今天、按需显示已完成。窄窗口允许横向浏览，不强行挤压七列。
- 周/月计划点击日期或任务才展开当天安排，点“＋ 安排”直接打开该天的添加条，详情可主动收起。工作台添加明确标为“添加到今天”；计划模式会显示目标日期，不把捕获任务与承诺日期混为一个隐式动作。
- 待办“改期”使用独立点选日历，提供今天、明天和任意日期，不改变正在浏览的日期。过期任务可单独或一次全部移到今天，保留原 ID、时间、子任务和完成状态；批量移动只进行一次持久化。过期指**今天以前**的未完成任务，不指今天早些时候的定时任务。
- 紧凑和完整待办共用 `TaskRowsModel`，在局部 ListModel 中按稳定 ID 插入、移除或移动行；标题、子任务或其他任务的完成状态变化，不再重置整个结果列表，避免展开区和草稿随列表重建消失。
- 删除主任务立即更新模型并保存，不等待卡片动画完成；底部提供单步撤销，恢复其日期、ID、子任务及完成状态。仅保留本次运行的最近一次主任务删除；子任务删除不支持撤销。
- 完整态下 Esc 优先关闭弹层、添加条、搜索或当天详情，再返回画布；`Ctrl+N` 添加、`Ctrl+F` 搜索，日历无详情时 `Alt+←/→` 切换周/月，有详情时切换天。
- 托盘提供打开日程、数据文件夹、退出，以及系统原生提醒通道。托盘/消息服务不可用时仍保留桌宠右键退出，紧凑态显示提醒气泡，展开及完整态提供不抢焦点的行内提醒。

## 存储和恢复

日程业务规则统一由 `CalendarTaskStore` / `TaskEntry` 负责，QML 与组件 API 调用同一实现。
移回收集箱（包括日终整理）会清空原时间；收集箱任务不能单独设置时间，重新安排日期也不会带回旧时间。
旧文件中残留的收集箱时间在内存恢复时清空，仍只在下一次有效修改时保存。
拖动与 API 排序统一为移到目标任务之前。日终整理在修改前校验整批选择，重复、已删除、已完成或已改期的任务
会拒绝整批操作，不会部分应用。API 只负责协议参数校验、权限和结果转换。

正常启动使用跨平台 `QStandardPaths.AppLocalDataLocation`，应用/组织名均为 Polaris。Windows 通常是 `%LOCALAPPDATA%\Polaris\Polaris`，Linux 通常是 `${XDG_DATA_HOME:-$HOME/.local/share}/Polaris/Polaris`；两侧数据默认独立，不要同时编辑同一文件。

- `tasks.json`：v2 UTF-8 JSON，`days` 保存有日期任务及手动顺序，`inbox` 保存未安排日期的任务；任务包含稳定 ID、标题、时间、完成状态、重点标记、多行笔记和一级子任务。统一校验跨日期及收集箱的 ID，禁止重复。
- v1 可以直接加载，保留原界面的时间顺序。首次有效修改才写入 v2，同时以 `tasks.v1-backup.json` 独立保留升级前的旧格式快照；读取和浏览不会擅自写入。升级后不要再用旧版本编辑同一份数据。
- 每次有效修改同步写入；`QSaveFile` 原子替换，不先截断已有文件。失败时保留内存修改，并在组件底部明确显示错误与重试入口，不显示“已保存”。正常退出会再次尝试保存；仍失败则必须明确选择“仍然退出”，不静默丢弃。
- `tasks.json.bak`：上一次完整有效快照。备份也使用原子替换；备份写失败时不继续覆盖主文件。首次写入没有历史备份。
- 主文件缺失/损坏时尝试加载有效备份。损坏原件另存为 `tasks.corrupt-时间戳.json`，界面提示恢复情况。**备份只保留上一版本，不等于完整历史，也不能保证包含最后一次修改。**
- 主文件和备份都无法读取、或遇到不支持的数据版本时，停止自动写入，显示错误，避免用空列表覆盖原件。修复文件后需重启；运行中临时的磁盘读写失败不会锁定为文件损坏，故障消失后可重试保存；重试不解除真实格式损坏的数据保护。
- 运行中检测到主文件格式损坏，同样停止覆盖。
- `app.lock` 使用 `QLockFile` 防止正常版本在同一系统/数据目录重复运行及并发写入。锁冲突时 Windows 弹出提示，其他平台输出错误，不再创建另一条鱼。不要假设它能提供 Windows/WSL 跨系统并发保护。旧的、未实现锁的可执行文件不受此机制控制，应退出后再使用新版。
- 托盘菜单可打开数据文件夹。手动备份可以复制 JSON；手动恢复应先退出应用、保存当前文件副本，再替换 `tasks.json`。
- 数据未加密，不包含账号或云同步；不要把本地文件放进仓库。

午夜后每 30 秒更新“今天”；若正在看昨天（原来的今天），自动跟随到新的一天；浏览其他日期时不打断。导航不会重复写入未修改的日程。

`create_engine()` 可显式指定存储路径，只装载界面和数据；正常 `main()` 使用用户数据目录，完成托盘订阅后才绑定并启动提醒协调器，避免首次提醒漏发。

## 已知边界

- 提醒仍按运行期提前十分钟规则；托盘原生通知受系统勿扰、系统权限和托盘可用性影响。不是系统级闹钟，不保证关闭程序后的提醒，未实现到点补报或跨重启去重。
- 暂无重复日程、云同步、拖拽改期、自动备份历史或导入向导。
- 未提交的“添加任务”草稿不是任务，不自动落盘；已有任务标题在 Enter、失焦、缩回或正常退出时提交，多行笔记在失焦、切换任务或正常退出时提交。
- 窗口位置、大小和界面筛选未持久化；任务顺序、重点和笔记属于持久化数据。
- 本轮不含专注计时器、工时统计或项目标签系统。
- 已复现并修复悬停移入/移出的闪暗：Qt 的 `transparent` 是透明黑，直接与浅色做 `ColorAnimation` 会经过明显偏暗的中间帧。动画背景统一使用保留白色 RGB 的零透明度 `Theme.clearSurface`。正常启动保持 Qt 默认渲染后端，不再用强制软件渲染掩盖颜色问题；时间弹层仍复用主窗口表面。
- 界面行为以实际运行中的点击、悬停和编辑体验为准。
