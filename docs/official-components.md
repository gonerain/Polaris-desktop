# 官方组件目录与契约基线

`next/official-components.json` 是本仓库维护的官方组件目录。它记录组件身份、入口、职责和**当前已声明**的能力，而非宣布所有操作已经稳定或通过替代实现认证。`platformApi: 1` 是组件接入协议版本，不是业务契约版本。未声明 `instances` 的清单按运行时默认策略为单实例；视图描述不代表允许创建多个组件实例或窗口。

基础组件是 authorization、collaboration、runtime；桌面组件是 window、canvas、pet、manager、sources、mcp、assistant。它们与业务组件承担不同职责，宿主相关替代实现还需满足相应宿主接口。画布负责窗口、导航、主题和分层设置；扩展管理正文及可信授权确认并入画布，manager 保留受信任管理后台；内置工作台应用负责组件视图及其布局，不是普通组件类型。画布尺寸和主题与工作台视图布局继续使用原有画布布局文件，无数据迁移。内置 assistant 是模型对话及授权工具执行组件；`org.polaris.agent` 是外部 Agent Bridge，二者不是同一组件。外部日程拥有任务数据；微信拥有账号和消息数据，目前还包含 Agent 编排，这部分边界有待迁入应用。微信单组件内部可有多个机器人，部分操作省略 `robot_id` 时使用界面当前选择；实例身份不能代替明确的机器人资源身份和授权。`org.polaris.feishu` 是既有 Linux 用户服务启动器；新组件 `org.polaris.feishu-bot` 独立提供多实例机器人连接与消息能力，二者身份和数据分别管理。`org.example.text-tools` 是示例，不列为官方核心组件。

目录的 `factory` 对应本仓内置 manifest 或所审外部清单；`factoryAliases` 记录观察到的其他入口，并不保证任意版本均可互换。外部仓库和当前本机安装不是此仓 CI 的输入：目录中的版本和声明是审计基线，必须在对应来源重新验证才能发布兼容承诺。外部仓库的工作树可能含未提交修改；它既不等于已发布版本，也不等于已安装副本。日程、微信和 Agent Bridge 工作树在此次审计时均有未提交修改，不能用这些修改推断已安装行为。

本机审计快照中，日程、微信、Agent Bridge 和 assistant 分别来自插件源修订，飞书来自本地组件；assistant 安装入口为 `polaris_assistant:create`，内置副本入口为 `components.assistant:create`。部分桌面组件安装记录使用 `polaris_platform.desktop:*`，与本仓 manifest 的 `components.*:*` 不同；MCP 也有独立入口。此快照仅说明一次安装，目录位置、修订和安装身份因机器而异。实际安装以自己的安装记录及来源为准。

官方组件是默认提供方，不是强制绑定。新应用应按明确版本的能力契约声明需求，并允许选择满足契约、权限和资源身份要求的第三方实现。新应用包可按 `contract` 和访问权限匹配能力，`preferredComponentType` 仅用于推荐排序；旧格式仍按 `componentType` 和操作筛选。两种绑定都要求操作声明 `applicationBinding=instance`，并校验具体安装和实例，因此只有满足这些条件的提供方可以切换。尤其不能对微信资源敏感操作仅加实例绑定标记就视为安全：先明确资源身份和授权边界。当前缺失 `provides`、参数/结果协议或替换验证的操作，均不因出现在目录中而成为稳定可替换契约。

变更已声明的 `provides`、访问权限、版本、参数或结果语义时，应检查调用方并明确兼容性；不兼容变更需要新的契约主版本。仓库测试核对内置 manifest 和assistant 及离屏画布描述，以及目录内所有已声明契约的版本格式。外部组件、桌面宿主行为、实际安装与第三方替换仍需各自的集成测试。

## 稳定接入约定与升级

本基线锁定组件 manifest 身份、入口、`platformApi: 1` 和未声明实例策略时默认为 `single` 的接入约定；组件实例与视图实例分别建模。已有 `provides` 必须具有明确主版本，操作的访问权限及接口语义属于契约的一部分；不得在同一主版本悄悄改变不兼容行为。这里锁定的是已声明的接入元数据，业务参数、结果和完整替换语义尚需逐项验证，不能由名称推断已经稳定。

升级时核对 manifest 身份、版本、工厂及实例策略；保留已发布入口或提供经测试的迁移。目录中的旧入口是已观察到的兼容入口，只有相应安装包实际提供并测试该入口时才能承诺兼容，不表示平台会自动重写入口。核对能力的主版本、读写权限、参数、结果与资源授权；不兼容的行为使用新主版本并安排调用方迁移。核对已保存连接、授权、数据及视图是否仍能恢复，外部组件由各自仓库验证。
