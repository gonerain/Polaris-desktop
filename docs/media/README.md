# Polaris 0.1.0.3 演示素材

`polaris-v0.1.0.3-real-demo.mp4` 是 23.3 秒、1280×720、20 fps 的无声产品演示。`polaris-v0.1.0.3-demo.gif` 是 768×432、10 fps 的循环预览。`polaris-demo-cover.png` 可用作封面。

演示使用真实 Qt 界面和隔离的虚构数据，展示桌宠打开画布、日程新增与完成、Agent 本机模型设置，以及缩小窗口后的画布导航。操作节奏经剪辑，界面按统一背景排版，不代表实时桌面速度。此版本未调用远程模型，也没有模拟模型回复或展示 AI 创建任务。

桌宠使用仓库自有的 `PetDefaultSkin.qml` 矢量备用外观，并在画面中标记为“演示外观”；它不是当前安装的默认皮肤，也不是新品牌角色。素材未使用 dsh-pet 人物美术。产品代码和该矢量外观遵循仓库 MIT 许可。

日程演示内容仅为“整理旅行资料（演示）”和“确认分享会提纲（演示）”。没有录制用户桌面、私密任务、真实聊天或密钥。Agent 设置画面显示现有环境变量提供配置，但不显示凭据值。

## English

The silent 23.3-second MP4 records real Qt views rendered in an isolated demo environment. It shows the desktop companion opening the canvas, adding and completing fictional schedule tasks, local Agent model settings, and canvas navigation after resizing. Timing is edited and the UI is arranged on a presentation background.

This edition makes no remote model call and contains no simulated AI response. The companion uses the repository's MIT-licensed vector fallback, labeled as a demo appearance. It does not depict the installed default skin or a new brand mascot. No private desktop, tasks, chats, or credential values are included.
