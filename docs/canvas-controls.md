# 画布背景与组件操作

## 操作分工

- 浅灰画布背景、外侧留白、格子间隙及空闲格负责移动整个桌面窗口；按下即交给系统原生移动。
- 外边缘和四角负责系统原生窗口大小调整，与组件标题条隔开，不再覆盖第一个组件的拖动区。
- 画布右上角 `− / 百分比 / +` 做整体缩放，范围80%..150%，每次10%；点击百分比恢复100%。屏幕放不下的比例不可选。
- 默认网格逻辑尺寸528×672；外围增加12px留白与32px画布控制区，100%时窗口552×728。较小屏幕首次展开会尽量降到能放下的比例。
- 缩放后逻辑模型、占格、草稿不变；手动放大窗口仍会让组件在各自 cell 内响应布局。缩放往返不累积整数舍入误差。
- 编辑弹层、完整态或移动过程中禁止冲突操作。独立完整态使用未缩放的界面，并准确映射缩放后的源组件矩形。

组件最上方的标题条只交换组件位置；日程日期区域、月历标题和 Agent 内部标题不再启动画布移动。
独立完整态中的原生窗口拖动能力不受画布组件规则影响。

## 输入边界

背景使用前置命中遮罩，按 `ComponentHost` 的实际区域排除组件。
组件自己的按钮、输入框和拖动条不会被背景抢走；最小化后的内容区、空 cell、间距仍可抓住移动画布。
此规则不区分日程、Agent 或新增组件，也不把未占格自动补成组件。

## 第一个组件换位

以前按指针所在 cell 判断目标，顶部组件必须拖过整行才有反应。
现在按相对按下点的位移识别方向，超过不大于48个逻辑像素的阈值即尝试换到邻格，半阈值回切以减少抖动。
位置仍仅在合法格点间做110ms单轴过渡，组件从不自由漂移或离开画布。

宽组件可能被多个单格组件共同挡住。分配器收集同轴换位组，保持各组件另一轴不变，
整组形状、边界及最终占用全部通过后才一次提交；任一冲突均保持原布局，不推挤到其他位置、不旋转、不重建模型。
例如上方两格日程与下方两个单格组件可以整行互换，也可以从任一单格组件发起反向交换。

## 验证与边界

临时诊断仅使用内存/临时存储，覆盖背景/组件输入分流、原生调整大小的入口、
首个组件短拖、满四格换行、分配器随机操作、80%/100%缩放往返、缩放后的完整态、草稿与占格保留。
不增加持久测试脚本；生产保留 Qt 默认渲染后端。

本次画布位置、比例和最小化仍仅在当前运行中保留，重启恢复默认布局。
