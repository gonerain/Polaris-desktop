# 微信组件

提供多机器人扫码绑定、微信消息收发、图片与文件保存和画布聊天视图。绑定后自动连接，首次使用自动回复默认关闭。

在顶部点击“新增绑定”扫码授权，通过下拉框切换机器人。绑定管理只保存服务端发放的微信连接，不负责在微信中创建独立联系人或聊天入口。各机器人保持独立连接，分别保存凭证、聊天、自动回复设置和任务回执；切换界面不会断开其他机器人。删除前需要确认，只清理所选机器人的本地绑定与记录。至少保留一个机器人，最后一个可通过“退出登录”解除绑定。

原有绑定继续作为“机器人 1”，沿用原来的数据文件。机器人列表和当前选择保存在 `robots.json`，新增机器人的数据保存在 `robots/<机器人 ID>/`。重启后恢复所有已绑定机器人的连接。凭证存储仍使用 Windows DPAPI 或 POSIX 0600 文件。

`get` 返回当前 `robotId`、`robots` 列表及当前机器人的消息；列表只含名称、标识和连接状态。收发、登录、附件及自动回复设置操作接受可选 `robot_id`，省略时使用当前选择。后台调用应显式携带机器人 ID，避免界面切换改变操作对象。管理操作为 `add_robot(name='')`、`select_robot(robot_id)`、`remove_robot(robot_id)`。

自动回复通过 `polaris.agent.reply@1` 委托处理消息。对话服务按公开能力发现；界面显示当前就绪状态。选择本次允许的操作并保存后，组件保存用户授权的自动回复任务，不自行授予权限。

只有收到的新消息会进入自动回复队列。用户关闭开关、新建对话或更换账号会取消旧轮次；回复确认发送成功后才确认该轮会话，发送结果未知时不自动重发。

`agent_control` 是运行中委托的回调入口：核对调用方、轮次和原微信账号，支持取消状态检查和附加本轮任务的回传地址。回调不能由模型自行选定。

任务结束通知及人工审批、提问回答通过绑定回执直接处理，不进入模型循环。通知记录保存在 `agent-completions.json`，人工交互记录保存在 `agent-interactions.json`；来源、账号和任务不匹配的回传会被拒绝。

## 图片与文件

收到绑定用户发送的图片或文件时，在后台下载并解密原文件，保存到 Linux `/tmp/polaris-weixin-<uid>/file-*/`。目录为 0700、文件为 0600；原文件名不能包含路径，单文件最多 20 MiB。下载与解密失败会显示附件保存失败。CDN 参数、账号令牌和解密密钥不进入消息正文。参考腾讯的 [iLink 媒体协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md)。Linux 解密使用本机 OpenSSL 的 libcrypto。

消息正文附带保存后的本地绝对路径，自动回复可以在用户要求时按公开能力转交这条文字。文件路径仅在可以访问该文件的本机宿主有效。临时目录被系统清理后路径失效；需长期保留的文件应由使用方另存。

文件能力：

- `save_attachment(attachment_id)`：保存当前账号收到的附件。`get.attachments` 提供附件标识及已保存文件信息。
- `write_file(name, content, encoding='utf-8')`：仅在组件自己的临时目录创建文件，支持 utf-8 或 base64；返回 `file_id,path,name,size,mime`。
- `read_file(file_id, encoding='utf-8', offset=0, limit=65536)`：只读取组件登记的文件，支持分段读取，单次最多 1 MiB。二进制使用 base64。

## 用户交互回传

调用声明 `interactionCallback` 的发送能力时，可选适配器附加 `receive_agent_request` 回调。通知绑定原任务、会话与微信账号，直接显示待批准操作或问题，不交给自动回复模型判断。回复格式：`批准 <编号>`、`拒绝 <编号>`、`回答 <编号> <答案>`；带选项的问题可用选项编号回答。普通文字不会被当成批准。

更新后重新挂载视图并确认新增能力，在自动回复设置中勾选目标的发送与交互回复操作后保存。回答沿用本次任务的已有授权；撤权、切换账号、重复回复、请求过期或已处理时不能继续原请求。通知与回复状态保存在 `agent-interactions.json`；一次性响应凭证不显示给用户或模型。

获取二维码时携带其他绑定最近的最多 10 个 bot token，仅用于微信服务端识别已有连接。`binded_redirect` 表示已连接过，界面明确提示本次未新增绑定，不将其误报为新增成功。重新扫码不能保证在同一微信账号下增加独立聊天入口。
