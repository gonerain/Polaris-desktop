打开日程界面后，可以新增、查看和调整任务，管理子任务并整理逾期事项。本地任务与 Google 日历事件分别保存在本机。

点击“Google 日历”，导入 Google Cloud 创建的桌面 OAuth 客户端 JSON，通过浏览器授权后选择要显示的日历。支持全天、跨天与重复事件，可在当天、周、月视图查看安排和事件详情。同步过去 90 天至未来一年，运行时每 5 分钟刷新，也可手动刷新。授权只读取日历，不修改 Google 事件。

首次连接需要自行启用 Google Calendar API 并创建桌面 OAuth 客户端；测试模式下将自己的账号加入测试用户。连接设置内提供 Google Cloud 入口与说明。令牌保存在系统凭据库；离线时保留已缓存安排并显示同步错误。

安装后启动组件，再从画布打开日程视图。
