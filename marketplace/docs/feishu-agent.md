在飞书继续 Codex CLI 的当前会话，并用原生交互卡片查看标记会话与日程任务。

在飞书发送「面板」或「日程」，即可切换页面、筛选、翻页和查看详情。点击刷新获取最新数据，操作更新原卡片，不反复刷屏。初版为只读展示；普通聊天、Codex 输出和 Bridge 结果回传保持原来的方式。

「提醒设置」可主动开启增量日程提醒：每小时只将新增、变更和刚进入关注范围的事项交给 AI 规划；到点校验后直接发送飞书，无增量不调用 AI。取消、完成或改期会作废旧的待发送提醒，变化以本机已同步数据为准。提醒计划、最近检查与发送记录保存在应用内，默认不开启。

安装或更新后，在应用连接中选择飞书、Codex CLI、Agent Bridge 和日程实例，确认所需权限。飞书相关能力连接同一机器人，Bridge 读取能力连接同一实例。首次新消息建立飞书连接，本机也提供卡片发送按钮。
